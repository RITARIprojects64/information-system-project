# Інформаційна система «Вебстудія»
## Призначення
Інформаційна система призначена для автоматизації обліку замовлень, управління списком клієнтів та зручного відстеження статусів виконання завдань у сучасному вебінтерфейсі.
## Основні функції
- Перегляд усіх замовлень у вигляді структурованої таблиці.
- Пошук у реальному часі за назвою, датою чи ID.
- Динамічна фільтрація замовлень за статусами («Нове», «У процесі», «Готово»).
- Інтерактивне модальне вікно підтвердження виходу з системи.
- Зручна навігація між розділами через бічне меню (сайдбар).
## Вимоги до середовища
- Будь-який сучасний веббраузер (Google Chrome, Mozilla Firefox, Microsoft Edge, Opera).
- Підтримка стандартів HTML5, CSS3 та JavaScript (ES6+).
## Порядок запуску
1. Завантажте файли репозиторію на свій комп'ютер у будь-яку папку.
2. Відкрийте файл `orders.html` у веббраузері.
3. Система готова до роботи та не потребує встановлення додаткового серверного середовища.
## Обмеження
- Система працює як інтерактивний вебпрототип (клієнтська частина без підключення до зовнішнього сервера).
